# À propos

`assembleer` est un projet R indépendant qui facilite l’exploitation des
données ouvertes publiées par l’Assemblée nationale française.

Les données sont issues des [jeux de données
officiels](https://data.assemblee-nationale.fr/). Le package n’est pas
un service officiel de l’Assemblée nationale.

Le téléchargement et l’actualisation sont explicites ; les analyses
s’exécutent localement dans DuckDB.
