# Rechercher dans les amendements de la base locale

Rechercher dans les amendements de la base locale

## Usage

``` r
chercher_amendements(texte, limite = 100L,
  cache = tools::R_user_dir("assembleer", "cache"))
```

## Arguments

- texte:

  Expression recherchee dans le dispositif, l'expose ou le titre.

- limite:

  Nombre maximal de resultats.

- cache:

  Repertoire local de la base.

## Value

Tableau des amendements trouves.
