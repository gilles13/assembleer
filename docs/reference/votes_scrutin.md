# Votes nominatifs d'un scrutin

Votes nominatifs d'un scrutin

## Usage

``` r
votes_scrutin(scrutin_uid, cache = tools::R_user_dir("assembleer", "cache"))
```

## Arguments

- scrutin_uid:

  Identifiant du scrutin.

- cache:

  Repertoire local de la base.

## Value

Votes enrichis des noms des deputes et du groupe au moment du vote.
